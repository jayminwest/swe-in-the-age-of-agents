# inbox

Raw captures for the book: Jaymin's own words, unedited. KOTA files "book:" texts, Flick notes and
voice-memo transcripts here verbatim, one file per capture: `YYYY-MM-DD-HHMM-<slug>.md`.

Rules:
- Files Jaymin adds himself can be named and formatted however he likes. The rules below are for agent-filed captures.
- Verbatim only. No cleanup, no expansion, no agent prose. Transcription fixes are limited to obvious mis-hearings (e.g. "Coda" -> "KOTA").
- Each file starts with: source (text / flick / voice memo), timestamp, and a one-line pointer to the BOOK_SPINE layer or chapter it seems to touch (KOTA's guess, marked as a guess).
- Jaymin promotes captures into roots ideas (`roots plant`) or the spine himself. Processed captures move to `inbox/done/`.
